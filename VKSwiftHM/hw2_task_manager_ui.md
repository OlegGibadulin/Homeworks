
# Домашнее задание 2: Интерфейс Менеджера задач (SwiftUI)

**Цель:** Оживить написанную ранее бизнес-логику, связав её с пользовательским интерфейсом. Вы освоите работу со списками, декларативную верстку и управление состоянием.

> 💡 **Совет:** Скопируйте модели `Task` и `TaskCategory`, а также класс `TaskManager` из первого ДЗ в свой новый iOS-проект.

## Что нужно сделать

### 1. Подготовка логики для SwiftUI
- [ ] Пометьте ваш класс `TaskManager` макросом `@Observable` (или подпишите под `ObservableObject` и добавьте `@Published` к массиву, если используете старый подход), чтобы интерфейс мог следить за изменениями в массиве задач.

### 2. Верстка отдельной ячейки (`TaskRowView`)
- [ ] Создайте отдельную структуру View для отображения одной задачи. Она должна принимать внутрь себя экземпляр `Task`.
- [ ] Ячейка должна состоять из `HStack` и отображать: 
  - Название задачи.
  - Иконку категории (из RawValue вашего `enum`).
  - Статус: используйте системные иконки (SF Symbols), например `circle` для невыполненной и `checkmark.circle.fill` для выполненной задачи.
- [ ] Покрасьте иконку статуса в зеленый цвет, если задача выполнена, или в серый/синий, если нет.

### 3. Экран списка (`TaskListView`)
- [ ] Сверстайте основной экран, используя компонент `List`.
- [ ] Свяжите UI с вашим `TaskManager` через `@State` (или `@StateObject`). Выведите массив задач в список, используя компонент `TaskRowView` для каждой строки.
- [ ] Добавьте `NavigationStack` (или `NavigationView`), чтобы у экрана появился заголовок (например, "Мои задачи").

### 4. Интерактивность
- [ ] Сделайте так, чтобы по нажатию на саму задачу (модификатор `.onTapGesture`) вызывался метод `toggleTaskCompletion` из вашего менеджера. Интерфейс должен обновиться автоматически (кружок закрасится).
- [ ] Добавьте в NavigationBar (через модификатор `.toolbar`) кнопку `+`.
- [ ] **Важно:** Полноценный экран создания задачи с текстовыми полями пока делать **НЕ нужно**. По клику на кнопку `+` просто вызывайте метод `addTask`, передавая туда захардкоженный текст (например, `"Новая задача"`) и случайную категорию.
