# ДЗ 2: Интерфейс менеджера задач (SwiftUI)

iOS-приложение на SwiftUI. Открыть `TaskManagerUI.xcodeproj`, выбрать симулятор iPhone и нажать ⌘R.

- `Task.swift` — модели `TaskCategory` и `Task`
- `TaskManager.swift` — логика, класс помечен `@Observable`
- `TaskRowView.swift` — ячейка задачи
- `TaskListView.swift` — экран со списком, кнопкой «+» и удалением свайпом
